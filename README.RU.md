# Vancore Support 🛰️
[English version](README.md)

**Vancore Support** — минималистичный Telegram-терминал для обратной связи. Создан для тех, кто ценит фокус и чистоту коммуникации.

## 🧬 Heritage
Проект построен на архитектурном фундаменте **DX Task**. Это эволюция: от системы управления задачами к системе управления смыслами. Мы взяли проверенную стабильность и адаптировали её для прямого диалога.

## 🛠️ Features
- **Anti-Flood Logic:** Строгий лимит (3 сообщения/день). Качество важнее шума.
- **Admin Reply System:** Ответы пользователям через нативный Reply.
- **SMI Architecture:** Single Message Interface. Ничего лишнего в чате.

## 🧠 The Vision: AI & Future
Я планирую интегрировать **Google Gemini AI**, чтобы превратить бота из почтового ящика в интеллектуальный фильтр.

> **Зачем здесь ИИ?**
> В мире избыточной информации внимание автора — самый ценный ресурс. ИИ не будет «отвечать за меня». Его задача:
> 1. **Отделять сигнал от шума:** Приоритезация баг-репортов и идей.
> 2. **Контекстная память:** Анализ истории обращений для понимания полной картины.
> 3. **Smart Summaries:** Краткие выжимки вместо бесконечных логов.

*Это не просто бот. Это инструмент для созидания.*

## 🚀 Quick Start
1. Переименуй `config.example.py` в `config.py` и укажи свои `TOKEN` и `ADMIN_ID`.
2. Установи зависимости: `pip install telebot`.
3. Запусти: `python bot.py`.
