## 🧭 Обзор и концепция

В мире информационного перегруза сфокусированное внимание создателя — самый ценный и дефицитный ресурс. Стандартные боты обратной связи либо превращаются в немодерируемую свалку сообщений, либо раздражают пользователей шаблонными роботизированными отписками.

**Vancore Support** спроектирован как прямой высокоточный терминал связи между аудиторией и разработчиком Даниилом.

Система работает на базе **Google Gemini** и выполняет роль архитектурного фильтра:
1. **Отделение сигнала от шума:** Сообщения анализируются в реальном времени, отсекая спам, бессодержательный флуд и бытовой оффтоп.
2. **Контекстная валидация:** Проверка технических баг-репортов и предложений по живому реестру продуктов экосистемы (DX Task, Metro Analysis, VPS Optimizer).
3. **Вечерний дайджест (Chief of Staff):** Автоматическая генерация емкой 24-часовой аналитической выжимки прямо в чат разработчика.

## ✨ Ключевые возможности

* **⚡ Моментальная сортировка через ИИ (`ai_engine.py`):** Входящие обращения проверяются на техническую релевантность и классифицируются (`ignore`, `thanks`, `feedback`, `important`) в формате строгого JSON.
* **🌐 Языковая адаптация:** Определение языка пользователя. Если сообщение на английском — ответ формируется строго на английском; если на русском — строго на русском.
* **📊 Суточный дайджест в 19:00:** Фоновый планировщик формирует вечерний отчет за последние 24 часа (Vibe Check, список багов с @юзернеймами, стоящие идеи и главный фокус).
* **💬 Нативные ответы через Telegram Reply:** Разработчик отвечает на сообщение бота обычным свайпом (Reply). Бот извлекает `#id` пользователя и отправляет ответ в его личный чат.
* **🛡 Защита от флуда:** Лимит 5 сообщений в течение 12 часов для одного пользователя обеспечивает высокое качество обращений.
* **🔄 Горячая перезагрузка (Hot Reload):** Команда администратора `/reload` обновляет модуль `ai_engine.py` на лету без перезапуска процесса бота.

## 🚀 Установка и запуск

### 1. Требования
* Python 3.10+
* Токен бота от [@BotFather](https://t.me/BotFather)
* Ключ API Gemini от [Google AI Studio](https://aistudio.google.com/)

### 2. Клонирование репозитория
```bash
git clone https://github.com/Vancore/vancore-support.git
cd vancore-support
```

### 3. Создание виртуального окружения
```bash
python3 -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Конфигурация
Скопируйте шаблон настроек:
```bash
cp config.example.py config.py
```
Откройте `config.py` и заполните ваши ключи:
```python
TOKEN = "ВАШ_ТОКЕН_БОТА"
ADMIN_ID = 123456789             # Ваш числовой Telegram ID
GOOGLE_API_KEY = "ВАШ_КЛЮЧ_GEMINI"
```

### 6. Запуск бота
```bash
python bot.py
```
*Файл базы данных `data.db` создастся автоматически при первом старте.*
