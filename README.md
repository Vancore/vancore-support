# Vancore Support 🛰️
[Russian version](README.RU.md)

**Vancore Support** — a minimalist Telegram terminal for feedback. Created for those who value focus and clarity of communication.

## 🧬 Heritage
The project is built on the architectural foundation of **DX Task**. It is an evolution: from a task management system to a meaning management system. We took proven stability and adapted it for direct dialogue.

## 🛠️ Features
- **Anti-Flood Logic:** Strict limit (3 messages/day). Quality over noise.
- **Admin Reply System:** Responding to users via native Telegram Reply.
- **SMI Architecture:** Single Message Interface. Nothing extra in the chat.

## 🧠 The Vision: AI & Future
I plan to integrate **Google Gemini AI** to transform the bot from a simple mailbox into an intelligent filter.

> **Why AI here?**
> In a world of information overload, the author's attention is the most valuable resource. AI won't "answer for me." Its task is:
> 1. **Separating signal from noise:** Prioritizing bug reports and breakthrough ideas.
> 2. **Contextual memory:** Analyzing interaction history to understand the full picture.
> 3. **Smart Summaries:** Concise daily digests instead of endless logs.

*It's not just a bot. It's a tool for creation.*

## 🚀 Quick Start
1. Rename `config.example.py` to `config.py` and specify your `TOKEN` and `ADMIN_ID`.
2. Install dependencies: `pip install pyTelegramBotAPI`.
3. Run: `python bot.py`.
